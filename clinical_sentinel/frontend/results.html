Youden's J Threshold Tuning & Trade-offs

Instead of default 0.5 classification thresholds, Clinical Sentinel optimises classification boundaries by maximizing Youden's J Index (Sensitivity + Specificity - 1) to balance diagnostic sensitivity and specificity.

Global Feature Importance (SHAP)

Mean absolute SHAP (SHapley Additive exPlanations) values computed across the validation set indicate global importance. Sepsis and Renal models rely heavily on Creatinine and Lactate values, while Respiratory models are influenced by WBC counts and Age.
